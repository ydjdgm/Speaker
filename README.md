# Speaker

**내 목소리와 유튜브 소리를 Discord·게임에 함께 보내고, 필요하면 WAV로 녹음하는 Windows 11 앱입니다.** USB 마이크를 사용하면서 Bluetooth 이어폰으로 내 목소리를 듣는 기능도 제공합니다.

```text
USB 마이크 + 선택한 프로그램 소리 → Discord / 게임 / 녹음 파일
USB 마이크                       → 내 이어폰으로 듣기
```

## 1. 앱 실행하기

프로젝트 폴더에서 `dist\Speaker\Speaker.exe`를 실행하세요.

다른 PC에서는 `dist\Speaker-1.0.0-windows-x64.zip`을 **모두 압축 해제**한 뒤 안에 있는 `Speaker.exe`를 실행하세요. EXE만 따로 옮기면 실행에 필요한 파일이 누락됩니다. 함께 들어 있는 DLL과 폴더를 유지하세요.

준비물은 **Windows 11 x64, USB 마이크, 이어폰**입니다. 다른 앱에 소리를 보내려면 아래의 VB-CABLE도 필요합니다. 내 목소리 듣기와 로컬 녹음만 사용한다면 VB-CABLE 없이 사용할 수 있습니다.

> 실제 장비에서의 앱 실행·음성 전달·녹음·지연은 사용자 최종 확인 대상입니다. 이 안내는 현재 소스의 버튼과 동작을 기준으로 작성했으며, 런타임 시험을 통과했다는 의미는 아닙니다.

## 2. 처음 한 번만: 가상 마이크 연결하기

VB-CABLE은 Speaker가 만든 소리를 Discord나 게임이 **마이크 입력**으로 받을 수 있게 연결해 주는 드라이버입니다.

1. Speaker의 **설정 및 진단 → 가상 마이크 연결 안내 → 공식 VB-CABLE 사이트 열기**를 누르세요.
2. [VB-CABLE 공식 사이트](https://vb-audio.com/Cable/)에서 Windows용 드라이버를 받아 압축을 푸세요.
3. x64 설치 프로그램을 관리자 권한으로 실행해 설치하고 PC를 재부팅하세요.
4. USB 마이크와 이어폰을 연결하고 Speaker를 다시 실행하세요.
5. **장치 / 프로그램 새로 고침**을 누른 뒤 아래처럼 선택하세요.

| 설정 위치 | 선택할 장치 |
|---|---|
| Speaker → 내 마이크 → 마이크 장치 | 실제 USB 마이크 |
| Speaker → 내 목소리 듣기 → 이어폰 | 실제 Bluetooth 이어폰 또는 유선 헤드폰 |
| Speaker → 전송과 녹음 → CABLE Input | CABLE Input (VB-Audio Virtual Cable) |
| Discord 또는 게임 → 입력 장치 | CABLE Output (VB-Audio Virtual Cable) |
| Discord 또는 게임 → 출력 장치 | 실제 이어폰 |

**Speaker에서는 `Input`, Discord·게임에서는 `Output`을 고릅니다.** 이름이 헷갈리면 아래 연결 순서를 기억하세요.

```text
Speaker → CABLE Input → CABLE Output → Discord / 게임
```

Windows 기본 재생 장치는 평소 사용하는 이어폰으로 유지하세요. Speaker는 Windows 기본 장치를 자동으로 바꾸지 않습니다.

## 3. 가장 많이 쓰는 방법: 유튜브와 내 목소리 함께 보내기

1. **Edge 또는 Chrome에서 유튜브를 재생**하세요. 통화는 별도의 Discord 앱에서 시작하세요.
2. Speaker의 **오디오 공유** 탭에서 **장치 / 프로그램 새로 고침**을 누르세요.
3. **내 마이크**에서 USB 마이크를 선택하고, **마이크 전달 음소거 (녹음에도 적용)**가 해제되어 있는지 확인하세요. 전달 음량은 우선 **100%**로 두세요.
4. **공유할 프로그램**에서 유튜브를 재생하는 브라우저를 선택하세요. 목록에는 `msedge`나 `chrome` 같은 이름으로 표시될 수 있습니다.
5. **프로그램 공유 ON**을 켜세요. 프로그램 전달 음량도 우선 **100%**로 두세요.
6. **CABLE Input**을 선택하고 **전송 ON → 가상 마이크**를 켜세요.
7. **전송 중** 상태와 레벨 막대를 확인하세요. Discord·게임의 입력이 CABLE Output이면 목소리와 유튜브 소리가 함께 전달됩니다.

내 이어폰에서는 유튜브가 평소처럼 재생됩니다. **내 목소리 듣기**는 원하는 경우에만 추가로 켜세요.

> **선택한 브라우저의 다른 탭·창 소리도 함께 전달될 수 있습니다.** 유튜브만 공유하려면 같은 브라우저의 다른 소리 나는 탭을 멈추세요. 통화를 같은 브라우저에서 하면 상대방 목소리까지 다시 전달될 수 있으므로, 통화는 별도 앱이나 다른 브라우저에서 하세요. 탭 하나만 선택하는 기능은 없습니다.

## 4. 버튼과 음량은 이렇게 구분하세요

| 조작 | 바뀌는 소리 |
|---|---|
| **내 마이크 → 전달 음량** | 상대방과 녹음 파일에 들어가는 내 목소리 크기 |
| **마이크 전달 음소거 (녹음에도 적용)** | 상대방과 녹음 파일에서 내 목소리만 제외 |
| **프로그램 공유 ON** | 선택한 프로그램 소리를 전송·녹음에 포함 |
| **공유할 프로그램 → 전달 음량** | 상대방과 녹음 파일에 들어가는 프로그램 소리 크기 |
| **내 목소리 듣기 ON** | 내 마이크 소리를 이어폰으로 듣기 |
| **듣기 음량** | 내가 듣는 목소리 크기만 조절 |
| **전송 ON → 가상 마이크** | 혼합 소리를 Discord·게임 쪽으로 보내기 |
| **녹음 ON → WAV 파일** | 혼합 소리를 파일로 저장하기 |

**전송·내 목소리 듣기·녹음은 각각 독립적입니다.** 전송을 꺼도 녹음할 수 있고, 전달용 마이크를 음소거해도 내 목소리 듣기는 유지됩니다.

| 하고 싶은 일 | 설정 |
|---|---|
| 목소리만 통화에 보내기 | 전송 ON, 프로그램 공유 OFF, 마이크 음소거 해제 |
| 유튜브만 통화에 보내기 | 전송 ON, 프로그램 공유 ON, 마이크 전달 음소거 |
| 목소리와 유튜브 함께 보내기 | 전송 ON, 프로그램 공유 ON, 마이크 음소거 해제 |
| 내 목소리만 이어폰으로 듣기 | 내 목소리 듣기 ON, 전송·녹음 OFF |
| 통화 없이 혼자 녹음하기 | 전송 OFF, 녹음 ON. 원하는 마이크·프로그램 소스 활성화 |

전송이나 녹음을 시작하려면 음소거되지 않은 마이크 또는 공유 중인 프로그램이 필요합니다. 사용할 소스의 전달 음량을 0%보다 높게 설정하세요.

## 5. 내 목소리 듣기

1. **내 마이크**에서 USB 마이크를 선택하세요.
2. **내 목소리 듣기**에서 실제 이어폰을 선택하세요.
3. **내 목소리 듣기 ON**을 켜고 **듣기 음량**을 편안한 크기로 조절하세요.

이 음량을 바꿔도 상대방에게 전달되는 목소리와 녹음 음량은 바뀌지 않습니다.

Bluetooth 이어폰에서는 목소리가 늦게 들릴 수 있습니다. 앱 설정만으로 무선 장비의 지연을 없앨 수는 없습니다. 지연이 불편하면 이 기능을 끄거나 유선 출력으로 비교하세요. **설정 및 진단 → 안정성 우선**은 끊김을 줄이기 위한 설정으로, 오히려 지연은 늘어날 수 있습니다.

## 6. 녹음하고 파일 관리하기

### 녹음

1. 녹음할 마이크와 프로그램을 선택하고 전달 음량을 맞추세요.
2. **녹음 ON → WAV 파일**을 켜세요. 녹음 상태와 경과 시간이 표시됩니다.
3. 끝나면 같은 체크를 해제하세요. **녹음 저장 완료**를 확인하세요.
4. **녹음 목록** 탭에서 저장된 파일을 확인하세요.

녹음에는 **내 목소리 + 공유 중인 프로그램 소리**가 들어갑니다. 녹음 중 마이크를 전달 음소거하거나 프로그램 공유를 끄면 그 변화도 파일에 반영됩니다. 내 목소리 듣기를 켜고 끄는 조작은 녹음 내용에 영향을 주지 않습니다.

기본 저장 위치는 Windows **음악 폴더 → Speaker Recordings**입니다. 파일은 `Speaker_날짜_시각.wav` 형식으로 저장되며, 긴 녹음은 **3시간마다 새 파일로 분할**됩니다. 저장 형식은 48 kHz / 16-bit / 스테레오 WAV입니다.

### 파일 관리

| 버튼 | 사용법 |
|---|---|
| **저장 폴더 열기** | 현재 저장 폴더를 탐색기에서 바로 열기 |
| **탐색기에서 보기** | 목록에서 선택한 녹음 파일의 실제 위치 열기 |
| **이름 변경** | 목록에서 녹음을 선택한 뒤 새 이름 입력 |
| **휴지통으로 삭제** | 선택한 녹음을 확인 후 휴지통으로 보내기 |
| **저장 위치 변경** | 다음 녹음부터 저장할 폴더 선택. 기존 파일은 이동하지 않음 |
| **없는 항목 정리** | 외부에서 이동·삭제되어 찾을 수 없는 파일의 목록 항목 정리 |

현재 녹음 중인 파일은 이름을 바꾸거나 삭제할 수 없습니다. 목록에는 Speaker가 관리하는 녹음만 표시됩니다.

녹음을 들어보려면 **프로그램 공유와 전송을 끈 뒤**, 탐색기에서 WAV 파일을 더블클릭해 기존 오디오 플레이어로 여세요. Speaker 안에는 재생 플레이어나 외부 MP3·WAV를 통화로 보내는 기능이 없습니다.

## 7. 사용을 마칠 때

- 상대방에게 보내는 소리만 멈추려면 **전송 ON → 가상 마이크**를 끄세요. 녹음과 내 목소리 듣기는 별도로 꺼야 합니다.
- 계속 사용하면서 창만 숨기려면 **최소화**하세요.
- 전송 또는 녹음 중 창을 닫으면 종료 확인이 나타납니다. 종료하면 전송·모니터링을 멈추고 녹음을 마무리합니다.
- 앱을 다시 열면 전송·프로그램 공유·내 목소리 듣기·녹음은 모두 OFF입니다. 필요한 기능을 직접 켜세요.
- Speaker를 끈 뒤에도 일반 음성 통화를 계속하려면 **Discord·게임의 입력 장치를 USB 마이크로 다시 선택**하세요.

## 8. 소리가 안 나거나 이상할 때

| 증상 | 확인할 것 |
|---|---|
| DLL 누락으로 실행되지 않음 | EXE만 옮기지 않았는지 확인하고 배포 ZIP 전체를 다시 압축 해제하세요. |
| CABLE Input이 목록에 없음 | VB-CABLE 설치·재부팅 후 **장치 / 프로그램 새로 고침**을 누르세요. |
| 상대방에게 아무 소리도 안 들림 | Speaker의 **전송 ON**, CABLE Input 선택, 통화 앱의 **CABLE Output** 입력을 확인하세요. |
| 목소리만 안 들림 | USB 마이크 선택, 전달 음소거 해제, 전달 음량을 확인하세요. Windows **설정 → 개인정보 및 보안 → 마이크**에서 마이크 및 데스크톱 앱 접근을 허용하세요. |
| 유튜브만 안 들림 | 실제 재생 중인 브라우저를 선택했는지, **프로그램 공유 ON**인지 확인하세요. 브라우저 자체 음소거도 확인하세요. |
| 음악이 통화에서 잘리거나 작아짐 | 통화 앱의 노이즈 억제·자동 입력 감도·자동 음량 처리를 조절해 비교하세요. |
| 상대방이 자기 목소리를 다시 들음 | 프로그램 공유를 끄고 통화 앱이나 통화 중인 브라우저를 공유 대상으로 선택했는지 확인하세요. |
| 내 목소리가 두 번 들림 | Windows 마이크 속성의 **이 장치로 듣기**, 통화 앱의 마이크 미리듣기 등 다른 모니터링을 끄세요. |
| Bluetooth에서 목소리가 늦게 들림 | 내 목소리 듣기를 끄거나 유선 출력을 비교하세요. 입력 장치는 이어폰 내장 마이크가 아닌 USB 마이크를 선택하세요. |
| 소리가 자꾸 끊김 | **설정 및 진단 → 안정성 우선**을 켜고 비교하세요. 설정 변경 시 소리가 잠시 끊길 수 있습니다. |
| 장치를 재연결했는데 동작하지 않음 | 새로 고침 후 장치를 다시 선택하고 필요한 기능을 직접 켜세요. 자동으로 다른 장치를 사용하거나 재개하지 않습니다. |
| 녹음이 저장되지 않음 | 화면의 오류를 확인하고 저장 폴더 쓰기 권한·디스크 여유 공간을 확인하세요. |
| 파일 이름 변경·삭제가 안 됨 | 녹음을 정지하고 해당 파일을 열어 둔 외부 플레이어를 닫으세요. |

오류가 계속되면 화면의 오류 문구와 **설정 및 진단** 내용을 함께 확인하세요. 진단의 내부 버퍼 지연은 Bluetooth·통화 앱·네트워크까지 포함한 전체 지연이 아닙니다.

## 9. 처음 설정한 뒤 한 번 확인하기

아래는 기본 사용 흐름을 확인하는 순서입니다. 각 단계의 기대 결과가 나타나야 합니다.

1. **실행:** 앱을 열면 전송·프로그램 공유·내 목소리 듣기·녹음이 모두 OFF인지 확인하세요.
2. **혼합 전송:** Discord 입력을 CABLE Output으로 두고 USB 마이크와 Edge의 유튜브를 공유하세요. 상대방에게 두 소리가 함께 들리고, 별도의 다른 프로그램 소리는 전달되지 않아야 합니다. 게임에서도 같은 입력 장치로 확인하세요.
3. **개별 조절:** 프로그램 공유 OFF에서는 목소리만, 마이크 전달 음소거에서는 프로그램 소리만 전달되어야 합니다.
4. **내 목소리 듣기:** 기능을 켜고 듣기 음량을 바꾸세요. 내가 듣는 크기만 바뀌고 상대방에게 들리는 크기는 유지되어야 합니다.
5. **독립 녹음:** 전송을 끄고 15초 정도 녹음하세요. 처음 5초는 목소리만, 다음 5초는 프로그램 공유 ON, 마지막 5초는 공유 OFF로 두세요. 녹음을 정지한 뒤 탐색기에서 파일을 재생하면 이 순서가 들려야 합니다.
6. **파일 관리:** 플레이어를 닫고 녹음 이름을 바꾸세요. 탐색기에서 새 이름을 확인하고 저장 폴더 열기를 확인하세요. 저장 위치를 바꿔 짧은 녹음을 하나 더 만들면 새 파일만 새 폴더에 저장되어야 합니다. 시험 파일을 삭제하면 휴지통에 나타나야 합니다.
7. **재연결과 종료:** USB 마이크를 분리하면 관련 오류가 표시되어야 합니다. 다시 연결하고 새로 고침·재선택해 복구하세요. 앱 종료 후 재실행하면 기능이 자동으로 켜지지 않아야 합니다.

장시간 녹음·3시간 분할·저장 실패·비정상 종료 복구의 상세 검증 안내는 로컬 프로젝트의 `docs\FINAL_TEST.md`와 배포 폴더의 `docs\FINAL_TEST.md`에 있습니다. 기본 확인만으로 이 항목들까지 검증됐다고 판단하지 마세요.
